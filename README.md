# bring-shrubbery/tap

Homebrew formulae for [Squish](https://github.com/bring-shrubbery/squish) tools.

```sh
brew install bring-shrubbery/tap/squish
```

| Formula | What it is |
|---|---|
| `squish` | The [squish CLI](https://github.com/bring-shrubbery/squish/tree/main/cli): finds the git worktrees your coding agents left behind and cleans them up safely. |

`Formula/squish.rb` is written by the squish repository's CLI Release workflow on every `cli-v*` release; don't edit it by hand.
